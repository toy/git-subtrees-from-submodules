# git-subtrees-from-submodules

Convert git submodules into subtrees while preserving contents and history (optionally squashing the history).

## Usage

> [!CAUTION]
> Back up your repository before running this script. Here be dragons.

```shell
./git-subtrees-from-submodules
./git-subtrees-from-submodules --squash
```
